## 2. วิธีเล่น (ฉบับปัจจุบัน)

- จอโปรเจกเตอร์มีกระดาน N ช่อง ปรับได้ 1–20 ช่อง ค่าตั้งต้นมี 11 ช่อง
- **เปิดการ์ดทีละช่องตามลำดับ 1 → ช่องสุดท้าย**
  - ถ้าคลิกช่องที่ยังไม่ถึงคิว จะขึ้นข้อความเตือน และช่องที่ถึงคิวจะเด้งให้เห็น
  - ไม่มีระบบตาเลือกช่องของทีม และไม่มีโบนัสเลือกช่องแล้ว
- **ไม่มีด่านลับแล้ว** การ์ด "Fun First, Results Follow" (ประเภทระดมพลัง) เป็นช่องสุดท้ายแบบปกติ
- ทุกทีมตอบข้อเดียวกันพร้อมกัน **เขียนคำตอบลงกระดาษ** แล้วยกพร้อมกันตอนหมดเวลา
  - ไม่มีระบบให้ทีมงานพิมพ์คำตอบของแต่ละทีมแล้ว
- พิธีกรกดเฉลย แล้วให้คะแนนได้ 3 ที่
  - บนการ์ด (+1/+2/+3)
  - แถบคะแนนด้านขวาของจอ (−1 +1 +2 +3)
  - หน้าหลังบ้าน
- **คะแนนต่ำสุดคือ 0 ห้ามติดลบ**
  - ปุ่ม −1 กดไม่ได้เมื่อทีมมี 0 แต้ม
  - ขโมยแต้มได้ไม่เกินที่ทีมนั้นมี
  - ถ้ายกเลิกรายการบวกเก่า คะแนนรวมก็หยุดที่ 0
- เวลาตั้งต้นของทุกโจทย์คือ 2 นาที (`sec:120`) แก้ได้รายข้อ
- เล่นจนถึงช่องสุดท้ายแล้วกด "ประกาศผล" จะมีโพเดียม และดาวน์โหลดรูปสรุปคะแนน (PNG) ได้
- ทีมตั้งต้นคือ 5 ทีม ชื่อ "ทีม 1–5" ถ้าเว้นชื่อว่างไว้จะขึ้นเป็น "ทีม N"

## 3. ประเภทการ์ด

| key | ชื่อบนจอ | สี | หมายเหตุ |
|---|---|---|---|
| `compass` | เข็มทิศ | `#1f6fd1` | คำถามจาก Town Hall |
| `friend` | รู้จักเพื่อน | `#2ea3dc` | |
| `idea` | ระดมพลัง | `#f2a516` | ช่องสุดท้าย "Fun First, Results Follow" ก็เป็นประเภทนี้ |
| `fun` | Fun | `#f47b20` | |
| `luck` | **จริงหรือมั่ว** | `#2c4a86` | ดูรายละเอียดด้านล่าง |

**รูปแบบการตอบ (`mode`)** ใช้ได้กับทุกประเภท ยกเว้นจริงหรือมั่ว

- `text`: ตอบเป็นข้อความ บนการ์ดมีช่องให้คะแนน
- `ab`: เลือก A หรือ B (A สีฟ้า, B สีส้ม) มีคำตอบถูกได้ 1 ข้อ
- `abcd`: เลือก A–D (C สีเขียว `#0f7a64`, D สีม่วง `#5d36b0`)
  - **คำตอบถูกได้หลายข้อ** ข้อมูล `correct` เก็บเป็นสตริง เช่น `"AC"`
  - บนจอไม่บอกล่วงหน้าว่ามีคำตอบถูกกี่ข้อ
  - ในหน้าแก้โจทย์ ติ๊ก checkbox เพื่อเลือกคำตอบที่ถูก
  - ถ้ายังไม่ได้ตั้งเฉลย ให้แตะเลือกบนจอหลายข้อ แล้วกด "ยืนยันเฉลย"

**การ์ดจริงหรือมั่ว (`type:"luck"`)**

- 1 การ์ดมีหลายคำถาม เก็บใน `items:[{q,optA,optB,correct}]`
- แต่ละข้อตอบ A (จริง) หรือ B (มั่ว)
- บนจอแสดงทีละข้อ กด ◀ ▶ เพื่อเปลี่ยนข้อ มีเฉลยและตัวจับเวลาแยกของแต่ละข้อ
- ค่า `luck` ของการ์ดกำหนดว่าจะทำอะไรต่อหลังตอบ
  - `"steal"`: ทีมที่ได้การ์ดขโมย 2 แต้มจากทีมอื่น 1 ทีม (ไม่เกินเท่าที่ทีมนั้นมี)
  - `"share"`: ทีมที่ได้การ์ด +2 และยกให้ทีมอื่นอีก +1
- **เลือกได้หลายทีม ทีละทีม** ทีมที่ใช้สิทธิ์แล้วจะขึ้น ✓ ระบบนับตามช่องของการ์ด (`sk`)

**ข้อมูลรุ่นเก่า** ถูกแปลงอัตโนมัติใน `normCard/normCards`

- `type:"choice"` → `compass` + `mode:"ab"`
- การ์ดดวงที่ยังไม่มี `items` จะได้คำถามว่าง 1 ข้อ
- ด่านลับ `cards.final` → ย้ายไปเป็นช่องสุดท้าย และย้ายสถานะ "เปิดแล้ว" กับคะแนน (`sk:"F"`) ไปเป็นของช่องนั้นด้วย

## 5. ข้อมูลและการซิงก์

**โหมดเครื่องเดียว (offline)** ใช้เมื่อไม่มี claude.ai db เช่นเปิดไฟล์ตรง ๆ หรือไม่ได้ Sign in เป็นผู้แก้ไข

- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์นั้น
- จอพิธีกรกับหน้าหลังบ้านซิงก์กันผ่าน `storage` event ต้องเปิด 2 แท็บในเบราว์เซอร์เดียวกันบนเครื่องเดียวกัน
- **ข้ามเครื่องไม่ได้** ถ้าจะย้ายไปเครื่องอื่น ให้ใช้ไฟล์ .json
- key ใน localStorage: `r2570-cards-v2`, `r2570-cfg-v3`, `r2570-state-v4`, `r2570-live-local`, `r2570-mute`, `r2570-narrate`
  - **ห้ามเปลี่ยนชื่อ key** ไม่งั้นข้อมูลที่เครื่องเก็บไว้จะหาย

**โหมด claude.ai (artifact + db)**

- capabilities ที่ใช้: `db`, `user`, `downloads`
- `useDb()=!!(db&&isEditor&&!demo)` ทุกเครื่องต้อง Sign in ด้วยบัญชีที่มีสิทธิ์แก้ไข
- เอกสารใน db
  - `game/live`: การ์ดที่เปิด, timer, scores, ชื่อทีม, qs, opened
  - `game/board`: `{opened, at, reset}`
  - `game/meta`: `{epoch}`
  - `game/config`: `{cards, cfg}`
  - คอลเลกชัน `scorelog`: แถวคะแนนตาม epoch
- แถวคะแนนมีรูปแบบ `{changes:[{t,d}],label,at,undone,round,sk,kind?,owner?}` โดย `sk` คือ `"tN"`
- คะแนนรวมคำนวณจาก log ทีละรายการตามเวลา และไม่ให้ต่ำกว่า 0 (`scoresFrom`, `floorChanges`)
- **ยังไม่เคยทดสอบโหมดนี้หลังการแก้ชุดล่าสุด** (ทดสอบแล้วเฉพาะโหมดเครื่องเดียว)

## 8. วิธีทดสอบ (สำหรับ Claude)

- **เช็ก syntax:** ดึงเนื้อหาจาก `<script>` สุดท้ายออกเป็นไฟล์ .js แล้วรัน `node --check`
- **เปิดในเบราว์เซอร์ของแอป:** เปิดตรงจาก file:// ไม่ได้ ให้ทำตามนี้
  1. สร้าง `.claude/launch.json` ชั่วคราว ให้รัน `python -m http.server 8765 --bind 127.0.0.1`
  2. `preview_start` แล้วไปที่ `/what-wodz-game.html`
  3. ลบ key `r2570-*` ใน localStorage ก่อนทดสอบแต่ละรอบ และลบอีกครั้งหลังทดสอบเสร็จ
  4. หยุดเซิร์ฟเวอร์ แล้วลบ launch.json
- **ทดสอบหน้าหลังบ้าน:** เปิดแท็บที่ 2 แล้วเรียก `nav("score")`
- กดปุ่ม "ข้าม" ที่หน้าแนะนำเกมก่อน
- การ์ดเปิดหลังวงล้อหมุนประมาณ 6 วินาที
- **แก้ไฟล์ใหญ่:** เขียนสคริปต์ python ที่ใช้ `rep(a,b)` และ assert ว่าเจอข้อความเดิมพอดี 1 ครั้งก่อนแทนที่ อย่าใช้ heredoc ยาว ๆ ใน bash เพราะพัง
- สำรองไฟล์ก่อนแก้ทุกครั้ง

## 9. งานค้างและสิ่งที่ยังไม่ได้ทดสอบ

- **ยังไม่ได้ publish** ต้องตัดสินใจว่าจะให้ Benz publish ทับลิงก์เดิม หรือสร้าง artifact ใหม่
- ยังไม่ได้ทดสอบการดับเบิลคลิกเปิดไฟล์ (file://) โดยปิด Wi-Fi บนเครื่องที่จะใช้วันงาน
- ยังไม่ได้ทดสอบโหมด claude.ai db (Sign in) หลังการแก้ชุดล่าสุด
- ยังไม่ได้ดูการ์ด A/B, A–D และจริงหรือมั่วบนจอมือถือ
- รอโจทย์จริงจาก Benz เพื่อแทนข้อความในวงเล็บ `[เติม…]` และรอไฟล์เสียง ElevenLabs สำหรับพากย์สาธิต (ถ้ามี)
