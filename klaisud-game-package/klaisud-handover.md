# ใกล้สุดชนะ · เกมที่ 2 · บันทึกส่งต่องาน

Company Outing 2569 (Debuz × GAMEINDY) · อัปเดตล่าสุด 7 พ.ย. 2569 · วันงาน (เดินทาง) 9–11 พ.ย. 2569

## สรุปสั้น

- เกมทายตัวเลข ทีมที่ทายใกล้คำตอบที่สุดได้คะแนน หน้าจอคิดคะแนนให้เอง
- **ใช้ไฟล์ `klaisud-game-offline.html` เป็นตัวหลัก** (ตัดสินใจ 7 พ.ย. 2569) ไฟล์เดียวจบ เปิดในเบราว์เซอร์ได้เลย ไม่ต้องมีเน็ต
- ทีมงานคุมเกมทั้งหมดได้จากหน้าจอใหญ่หน้าเดียว แชร์จอแค่แท็บนี้แท็บเดียวพอ คำตอบจริงไม่โผล่บนจอใหญ่จนกดเฉลย
- ลิงก์ artifact บน claude.ai ยังมีอยู่ แต่เป็นตัวรอง (ดูหัวข้อ "ลิงก์ artifact")

## ย้ายไปเครื่องใหม่

### สิ่งที่ติดไปกับโฟลเดอร์ และสิ่งที่ไม่ติดไป

| ติดไปกับโฟลเดอร์ | ไม่ติดไป (ต้องทำเอง) |
|---|---|
| ตัวเกม เสียงพากย์ ฟอนต์ สคริปต์ build ไฟล์นี้ | **ข้อมูลเกมที่ตั้งไว้** (ชื่อทีม โจทย์ คำตอบ คะแนน ประวัติ) อยู่ในเบราว์เซอร์ของเครื่องเดิม ต้องย้ายผ่านไฟล์สำรอง `.json` |
| ไฟล์สำรองที่บันทึกไว้ในโฟลเดอร์ (`klaisud-backup-*.json`) | ความจำของ Claude ในเครื่องเดิม (ไฟล์นี้คือข้อมูลทั้งหมดที่ Claude ต้องรู้แทน) |

### ขั้นตอน

**ที่เครื่องเดิม**
1. เปิด `klaisud-game-offline.html` ไปที่หลังบ้าน กดไอคอนเฟือง (ตั้งค่า) เลื่อนลงไปที่ "สำรองข้อมูล" กด **บันทึกไฟล์สำรอง**
2. ย้ายไฟล์ `klaisud-backup-ปี-เดือน-วัน-เวลา.json` ที่ได้ (อยู่ในโฟลเดอร์ Downloads) มาไว้ในโฟลเดอร์เกม
3. zip ทั้งโฟลเดอร์ `klaisud-game-package` แล้วย้ายไปเครื่องใหม่

**ที่เครื่องใหม่**
1. แตกไฟล์ zip ไว้ที่ไหนก็ได้ เช่น `Downloads\klaisud-game-package`
2. ดับเบิลคลิก `klaisud-game-offline.html` ให้เปิดด้วย **Chrome หรือ Edge** (ไม่ใช้โหมดไม่ระบุตัวตน)
3. ไปที่หลังบ้าน → ไอคอนเฟือง → สำรองข้อมูล → **นำเข้าไฟล์สำรอง** เลือกไฟล์ `.json` ล่าสุด แล้วกด "แทนที่ด้วยไฟล์นี้"
4. เช็กว่าชื่อทีม โจทย์ และคำตอบครบ (ป้ายด้านบนหน้าตั้งค่าต้องขึ้น "พร้อมเล่นแล้ว")
5. ลองเปิดหน้าจอใหญ่กับหลังบ้านคนละแท็บ พิมพ์ตัวเลขในแท็บหนึ่งแล้วดูว่าอีกแท็บอัปเดต

เล่นเกมอย่างเดียวไม่ต้องติดตั้งอะไรเพิ่ม ส่วนที่ต้องติดตั้งเฉพาะตอนจะแก้โค้ด

- **Node.js 18 ขึ้นไป** ใช้สร้างไฟล์ offline ใหม่ (`node build-offline.mjs`) ตอนนี้ใช้ v24
- **Python 3** ใช้เปิดเซิร์ฟเวอร์ทดสอบในเครื่อง (ไม่บังคับ)

ไฟล์สำรองล่าสุดที่อยู่ในโฟลเดอร์ตอนเขียนบันทึกนี้: `klaisud-backup-2026-11-07-2307.json` (7 พ.ย. 2569 23:07) ถ้าแก้ข้อมูลหลังจากนั้น ให้บันทึกไฟล์สำรองใหม่ก่อนย้าย

### แก้โค้ดแล้วสร้างไฟล์ใหม่

1. แก้ `klaisud-game.html`
2. รันในโฟลเดอร์เกม: `node build-offline.mjs` (ขึ้น `klaisud-game-offline.html  2.13 MB` แปลว่าสำเร็จ)
3. **รีเฟรชทุกแท็บที่เปิดเกมอยู่ (Ctrl+F5)** ถ้าไม่รีเฟรช แท็บเดิมจะรันโค้ดเก่าต่อ (เคยเกิดแล้วทำให้เห็นคะแนนติดลบทั้งที่แก้แล้ว)
4. ข้อมูลเกมไม่หายตอน build เพราะอยู่ในเบราว์เซอร์ ไม่ได้อยู่ในไฟล์

## กติกาเกม

- ข้อปกติ: ใกล้สุด +3, อันดับ 2 +2, อันดับ 3 +1, ทีมอื่น 0 · ทายห่างเท่ากันได้อันดับเดียวกัน
- รอบเดิมพัน (ข้อที่ติ๊ก "รอบเดิมพัน ×2" ตอนนี้คือข้อ 7 และ 9): ทุกทีมลงแต้ม 0–3 ทีมใกล้สุดได้แต้มเดิมพัน ×2 ทีมอื่นเสียแต้มที่ลงไว้ ทีมที่ไม่ได้ตอบไม่เสียแต้ม
- **คะแนนต่ำสุด 0 ห้ามติดลบ**: ทีมที่แพ้เดิมพันเสียได้ไม่เกินแต้มที่มีตอนนั้น และกด −1 ไม่ได้เมื่อทีมมี 0 คะแนน
- ประเภทข้อ
  - **HR เติมคำตอบ**: ใส่คำตอบล่วงหน้าในหน้าตั้งค่า จอใหญ่ไม่เห็นจนกดเฉลย
  - **ตอบสดในห้อง**: นับหรือถามในห้องก่อน แล้วพิมพ์คำตอบในหลังบ้าน (จอใหญ่ไม่มีช่องคำตอบ)
  - **ไม่มีคำตอบกลาง**: กดเฉลยได้เลย ระบบใช้ตัวเลขสูงสุดของทีมเป็นคำตอบ ทีมที่ตัวเลขสูงสุดชนะ
- ไทม์ไลน์: อธิบายกติกา 5 นาที · ข้อละประมาณ 4 นาที · ประกาศผล 5 นาที

## วิธีใช้วันงาน

1. ใช้โน้ตบุ๊กเครื่องเดียวต่อโปรเจกเตอร์ ตั้งจอแบบ **Extend** (ไม่ใช่จอซ้ำ)
2. เปิด `klaisud-game-offline.html` ใน Chrome หรือ Edge
3. **แบบหน้าเดียว (แนะนำ)**: ลากหน้าต่างจอใหญ่ไปที่โปรเจกเตอร์แล้วกด F11 ทีมงานกรอกตัวเลข กดเฉลย และเปลี่ยนข้อได้จากหน้านี้เลย ถ้าแชร์จอผ่านโปรแกรมประชุม ให้เลือกแชร์แค่แท็บนี้
4. **แบบสองหน้า**: เปิดอีกหน้าต่างเป็นหลังบ้านบนจอโน้ตบุ๊ก ใช้ตอนต้องพิมพ์คำตอบข้อตอบสด หรือปรับคะแนน ±1
5. กดบันทึกไฟล์สำรองเป็นระยะระหว่างเล่น
6. ข้อควรระวัง: ห้ามเปิดในโหมดไม่ระบุตัวตน ห้ามล้างข้อมูลเบราว์เซอร์ ข้อมูลผูกกับเบราว์เซอร์ที่ใช้เปิด (Chrome กับ Edge ไม่เห็นข้อมูลของกันและกัน) ถ้าเปลี่ยนเบราว์เซอร์ ย้ายไฟล์ไปโฟลเดอร์อื่น แล้วข้อมูลไม่ขึ้น ให้นำเข้าไฟล์สำรอง
